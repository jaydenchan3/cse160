Notes to Grader:

  • Mini Minecraft survival in a 32x32 voxel world.
  • Walk: WASD. Look: click + drag on the canvas. Pan: Q/E.
  • Place block: F (1/2/3 to switch dirt/stone/wood). Remove block: G.
  • Goal: walk near each of the 5 gold blocks scattered around the map to pick them up. Counter is in the status line below the canvas.
  • Wow factor: animated 60-second day/night sky cycle (dawn → day → sunset → night).
  • World is built from a hardcoded 32x32 height map. Geometry is merged into one VBO per block type with face culling so the whole world renders in a few drawArrays calls.
  • Camera class lives in camera.js (WASD / Q/E / mouse drag, pitch clamped to ±85°).
  • generate_textures.js is a one-shot Node script I used to make the placeholder PNGs in textures/ grader doesn't need to run it.
